# Gang 设计规范

**参考**：blur.io 的终端气质。一种等宽字体贯穿全站，近黑背景，1px 细线，大写小字标签，密集行情表，几乎没有装饰。品牌色沿用币安黄，表明生态归属。

## 字体

- 全站只用 **Geist Mono**（OFL 开源，气质最接近 Blur 的 Proto Mono），自托管（`@fontsource/geist-mono`），不依赖 Google Fonts。
- 正文 13px / 20px；表格 12px；微标签 11px 大写、字距 0.08em；标题 24–32px、字重 500、字距 −0.02em；统计数字 22px。
- 数字启用 `tnum` 等宽对齐。

## 颜色

| 角色 | 值 |
|---|---|
| 页面 | `#080808` |
| 面板 | `#0E0E0E`，悬停 `#141414`，选中 `#1A1A1A` |
| 细线 | `#1F1F1F`，输入框边 `#303030` |
| 文字 | `#E6E6E6` / 次 `#929292` / 弱 `#5C5C5C` |
| 品牌 / 强调 | `#FCD535`（币安黄） |
| 涨 / 买 | `#0ECB81`；跌 / 卖 `#F6465D` |

## 形态

- 圆角 4px，边框 1px，无阴影无渐变无扫描线。
- 面板标题栏 40px，标题为大写微标签；tab 选中态用浅灰底。
- 行情表行高 44px，表头大写微标签；曲线进度 3px 细条。
- 命令框前缀 `$`，复制按钮大写微标签。
- 标题末尾下划线光标闪烁，是唯一的动效。

## Logo

文字版 logo：自绘的粗像素字母 **GANG**，每个字母 6×7 格、2 格笔画，字间距 1 格，整体 27×7 格。币安黄，`crispEdges`。顶栏以 3px/格 渲染（81×21），后面跟一个闪烁的黄色光标块。头像用黄底黑字反白，favicon 用单个像素 G 黄底黑字。资源在 `web/public/brand/`：`mark.svg`、`lockup.svg/png`、`avatar.svg/png`、`og.svg/png`；`web/public/favicon.svg`。
