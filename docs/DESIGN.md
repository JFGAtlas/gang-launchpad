# Gang 设计规范

**定位**：Binance 生态项目（Binance Agentic Wallet、BNB Chain）。视觉语言直接对齐 Binance 产品 UI，让用户一眼认出"这是币安生态里的东西"。

## 颜色

| 角色 | 值 | 变量 |
|---|---|---|
| 页面背景 | `#0B0E11` | `--bg` |
| 面板 / 顶栏 / 页脚 | `#181A20` | `--bg-2` |
| 面板内强调、输入框 | `#1E2329` | `--bg-3` |
| 分割线、进度条底 | `#2B3139` | `--line` / `--bg-4` |
| 主文字 | `#EAECEF` | `--text` |
| 次文字 | `#B7BDC6` | `--text-2` |
| 弱文字、表头 | `#848E9C` | `--text-3` |
| **品牌 / 主操作 / 选中** | `#FCD535`，hover `#F0B90B` | `--yellow` |
| 主按钮文字 | `#181A20` | `--on-yellow` |
| 涨 / 买 / 已毕业 | `#0ECB81` | `--green` |
| 跌 / 卖 | `#F6465D` | `--red` |

黄色是唯一的品牌色：logo、主按钮、选中的 tab、内盘进度条。绿红只表示涨跌和买卖，不做装饰。

## 字体

- 正文与标题：IBM Plex Sans（Binance 自有字体 BinancePlex 的开源底版），中文回落 PingFang SC / Noto Sans SC。
- 数字、地址、命令：IBM Plex Mono，启用 `tnum`。

## 形态

- 圆角 4px（按钮、标签、输入）与 8px（面板）。
- 行情用**密集表格**，不用卡片：Token / 价格 / FDV / 24h 量 / 24h 笔数 / 持有人 / 曲线进度 / 时间。
- 顶栏 64px，深色面板底，黄色 logo 在左，导航在旁，状态 chip 在右。
- Tab 用黄色下划线表示选中。
- 动效只有 hover 的背景过渡（120ms），无发光、无渐变、无扫描线。

## 反模式

- 不用霓虹青 / 品红 / 紫色 AI 渐变。
- 不用 emoji 当图标。
- 不在页面里放"连接钱包"或买入按钮：购买只通过 agent 完成，页面只展示和引导。
